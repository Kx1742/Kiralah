# Worked examples

Each file is a bill plus the answer worked out **by hand**, independently of the engine, so a test failure means one of them is wrong.

These are modelled on common Malaysian receipt formats (mamak, kopitiam, restaurant with service charge and SST, vouchers and promos). They are **not scans of real receipts**: dish names and prices are illustrative. Real receipts should be added here as they are collected, in the same format.

Amounts are integer sen. Rates are basis points (1000 = 10%).
